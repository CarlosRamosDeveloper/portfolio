# Portfolio de Carlos Ramos Dev

Este proyecto es mi portfolio personal, bienvenidos

## Tecnologías y herramientas

- pnpm
- React
- Typescript
- Tanstack Query
- React Router
- Github projects
- Shadecn/ui

## Preparación del proyecto

Para instalar todas las dependencias del proyecto, ejecutar en la raiz del proyecto el siguiente comando

>pnpm i

## Ejecución del proyecto

Para arrancar el comando ejecutar la siguiente línea de comandos en el terminal, en la raíz del proyecto.

>pnpm dev
